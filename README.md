# smartflow-backend

This repository currently contains the SmartFlow backend, and it now also includes imported files from the `urbanflow` repository branch `bhushan/backend`.

The imported branch contains a React + Vite frontend setup with the following top-level structure:

- `package.json`, `package-lock.json`
- `vite.config.js`
- `src/` and `public/` frontend assets
- an additional nested `urbanflow/` frontend subdirectory

## Notes

- The backend-specific files remain in `backend/`, `data/`, and related Python scripts.
- The imported frontend files are present in the current branch as part of the merged content.
- This merge was performed on the local branch `import-urbanflow-bhushan-backend`.
